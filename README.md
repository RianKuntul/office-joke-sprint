# One-Line Office Joke: 24-Hour Sprint

Entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) competition on [make.fun](https://make.fun).

`main.ts` (Node 22) writes a single-line joke about office life — the sort of
line you send a colleague after a meeting that should have been an email —
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). A read-back gate
refuses to write anything outside 1–200 characters, anything whitespace-only,
or anything spanning more than one line.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-sprint-out node main.ts
```
